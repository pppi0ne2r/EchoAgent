connecting

普通更新和下载不用重启，已有容器可以直接使用。只有容器缺少新的挂载点时才需要，而且会中断正在运行的任务。

知识库

可以填 GitHub 仓库主页，例如 https://github.com/swisskyrepo/PayloadsAllTheThings。会下载默认分支，并把整个仓库添加为一个知识库。也可以填文件或 zip 直链，或本地导入。不要填名称。已有容器可以直接使用。

工具库

可以填 GitHub 仓库链接，或本地导入二进制、jar、zip。不要填名称，也不要填 release 压缩包。例如 https://github.com/projectdiscovery/katana。名称用仓库名。能唯一确定 linux/arm64 发布包时下载发布包，否则下载默认分支。添加后会立即下载。已有容器可以直接使用。

Skill

https://github.com/ljagiello/ctf-skills 是内置预设，首次启动会自动导入。也可以再填其他 GitHub 仓库主页。会下载默认分支，并把根目录或每个一级子目录里的 SKILL.md 分别添加。也可以填 SKILL.md、单个 skill 的 zip 直链，或本地导入。单个 zip 的 SKILL.md 只能在根目录或套一层目录，开头必须有 name 和 description。Codex 会读取 /home/kali/.agents/skills。已有容器可以直接使用。

目标

配置

调度、容器和 Codex。保存后只影响之后启动的项目。

调度

控制同时跑几个项目，以及每个项目能开几个 Codex。这不是容器的 CPU 或内存。

容器

内存、CPU 和容器内 Clash。正在运行的容器不会被重启。镜像和 Dockerfile 仍由配置文件决定。

0 表示不限制。只作用于之后启动的普通项目。加密题目继续使用自己的预算。

开启后，容器内遵守代理变量的程序走 127.0.0.1:7890。容器需要能直接访问订阅地址。失败时看 /tmp/mihomo.log。

Codex

接口、模型和密钥。密钥留空表示不修改。
